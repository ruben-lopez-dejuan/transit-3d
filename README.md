# Bilbao Transit 3D

Current clean baseline:

- Vite + TypeScript frontend.
- Provider-based backend structure.
- Safe downloader.
- Bizkaibus static GTFS provider.
- GTFS validation test.

## Setup

```powershell
npm install
```

## Test Bizkaibus GTFS

```powershell
npm run test:bizkaibus-gtfs
```

## Build

```powershell
npm run build
```

The next commit should add the Bizkaibus GTFS-Realtime provider.
